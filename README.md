# movie-finder

## Руководство пользователя

После открытия сайта вы увидите карточку поиска с полями для выбора года выпуска фильма и жанра, а также блок «Исключить темы», где можно отметить нежелательные ключевые слова (например, «насилие», «кровь», «депрессия») или добавить свою тему через текстовое поле. Чтобы начать подбор идеального фильма, убедитесь, что в поле «Год выпуска» указано значение от 1890 до текущего года, выберите интересующий жанр из выпадающего списка (или оставьте «Любой жанр»), затем отметьте те слова, которые не должны встречаться в описании фильма, и нажмите большую оранжевую кнопку «Найти идеальный фильм». После короткой загрузки сайт покажет сетку карточек фильмов, где для каждого фильма отображаются постер, название, год выхода, рейтинг, краткое описание и первая доступная рецензия из базы TMDB. Если описание фильма содержит хотя бы одно из исключённых слов, такой фильм автоматически скрывается из результатов, а если подходящих фильмов не найдено, вы увидите соответствующее сообщение и сможете смягчить условия поиска.

## Руководство разработчика

Сайт построен на трёх основных файлах: `index.html` (структура страницы), `style.css` (визуальное оформление в стиле стекломорфизма с тёмной темой) и `script.js` (вся клиентская логика, включая взаимодействие с The Movie Database API). Для работы приложения необходимо получить бесплатный API-ключ на сайте `themoviedb.org`, зарегистрировав приложение типа «Browser», и вставить этот ключ в переменную `TMDB_API_KEY` в начале `script.js`; после этого все запросы к эндпоинтам `/discover/movie`, `/movie/{id}` и `/movie/{id}/reviews` будут выполняться с корректной аутентификацией. Логика поиска использует параметры `primary_release_year` и `with_genres` для фильтрации по году и жанру, затем для каждого из первых 12 фильмов загружается полное описание и рецензии, после чего функция `isDescriptionValid()` проверяет описание на наличие слов из множества `excludedKeywords` (которое пользователь пополняет через чипы и пользовательский ввод). Все ошибки API, отсутствие ключа или некорректный год обрабатываются с выводом понятных сообщений, а для запуска достаточно любого локального HTTP-сервера (например, `python -m http.server 8000` или расширение Live Server в VS Code). При желании разработчик может легко расширить набор жанров, добавив в HTML-элемент `select` новые опции с правильными числовыми идентификаторами жанров TMDB, или изменить список стандартных исключаемых тем в блоках с классом `exclude-tag`.
